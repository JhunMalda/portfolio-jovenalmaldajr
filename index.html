01 — ABOUT

Four years of shipping pixel-perfect, accessible interfaces.

Caloocan City, Philippines-based. Comfortable working solo or inside a team.

I'm a web developer with 4+ years of hands-on experience building responsive, accessible web interfaces using HTML, CSS, and JavaScript — and, more recently, React and Next.js. I care about writing clean, maintainable code and about translating a design file into something that actually feels as good as it looks in the browser.

Most of my work has been on multi-page corporate sites and listing platforms for clients in Japan — translating Figma designs into pixel-perfect, cross-browser-compatible builds while keeping WCAG accessibility standards in mind, and optimizing assets and load performance along the way.

More recently I've folded AI tooling into that workflow — using ChatGPT, Claude, and Figma Make to move through builds faster — while still doing the fundamentals by hand: semantic markup, considered CSS, and JavaScript that doesn't get in the way.

04 — HOW I WORK

Same four stages, every build.

Design first, code second, polish always.

STAGE 1

Understand the brief

What the site needs to do, who it's for, and what "done" looks like before any code gets written.

STAGE 2

Turn the design into markup

Figma becomes semantic HTML and considered CSS — structured to hold up as the site grows.

STAGE 3

Add interactivity & polish

JavaScript, animation, and accessibility passes, checked across browsers and screen sizes.

STAGE 4

Test, optimize & ship

Assets optimized, images lazy-loaded, performance checked, then it goes live.
